# Finance Dashboard

A personal finance dashboard for tracking income, expenses, budgets, and net worth over time.

## Features

- Income and expense tracking
- Budget management
- Net worth visualization
- Monthly and yearly reports

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React + TypeScript
- Recharts for data visualization
- Tailwind CSS
